# 个人迭代系统 · 独立问题金字塔预览

这是**设计候选**，不是生产页面。此目录不参与 Astro 页面路由或管理员 API。

## 如何预览

直接下载本目录的 `iteration-tree-offline-v1.html` 并用 Safari 或 Chrome 打开。所有 CSS、交互脚本和虚构演示数据都在一个文件内，不需要构建、Vercel、Cloudflare、网络请求或登录。

若要检验真实问题链，在本地点击「导入 iteration-current.md」，选择本人私有仓库中的文件。解析过程仅在本机浏览器执行；**绝不能将私人 Markdown 或其内容提交到此公开仓库**。

## 验收清单

- [ ] 视觉：桌面和移动端均应具有完整独立样式，不依赖生产网站样式文件
- [ ] 结构：能看见父问题→执行问题→具体卡点，并识别最深焦点
- [ ] 交互：点问题切换详情，每层有独立四步圆盘；点击阶段不改写真实进度
- [ ] 树：可以折叠/展开子问题、切换问题链、按关键词搜索
- [ ] 隐私：页面无外部资源，导入的私人 MD 不上传、不在公共源码中
- [ ] 适配：桌面、Safari、iPhone 尺寸、键盘操作及减少动画偏好均正常

**注意：**仅在用户确认设计和交互体验满意后，再讨论如何将样式与代码集成到受保护工作台。合并本原型 PR 不是发布生产网站，不解决 Vercel 构建限额。
