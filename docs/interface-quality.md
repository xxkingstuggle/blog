# MYZJX 界面质量基线

> 2026-11-13 · 本文记录本轮视觉审计的可重复判断标准；设计改动仍在草稿 PR，不代表生产已更新。

## 参考与定位

主要对照对象为 Godly.Design 的 \`/sites/\` 列表、桌面和 iPhone 版截图、网站详情页。我们复制的是阅读与浏览的信息层级、导航节奏及清晰反馈，不复制第三方封面、品牌素材或没有证据的 UI 功能。以 MYZJX 的实际文章、产品状态、软件截图为准。

### 判断错误设计的五种信号

1. 同一个高竖框容纳所有媒体：横向软件截图只占画框很小一块，产生无用空白。
2. 无图片时用重复的同心圆/巨型 Unicode 图标代替内容：无法帮助访客理解真实项目。
3. 同一张截图在相邻列表重复出现：独立作品与关联文章看起来像重复条目。
4. 交互动效叠加：滚动淡入、滤镜扫光、卡片缩放、全页位移同时出现。
5. 原样照搬英文信息设计：中国字数、标签长度、版本说明和小屏幕文字需要自己的排版。

## 本轮落地规则

- 公共作品卡片：\`GalleryCard.astro\` 从 Astro \`ImageMetadata.width/height\` 推算预览比例，并限定在 \`0.82–1.64\` 区间；无图时采用正文导读卡片，不使用装饰性环形动画。内容不应因为外框而缩成过小的截图。
- 多列列表：\`gallery-layout.ts\` 使用原生 CSS Grid 作为降级实现，支持时以测量行跨度紧凑排列。移动端保持正常单列顺序。ResizeObserver 只读元素大小，并通过 RAF 合并布局写入。
- 公共首页：同一来源的媒体预览只出现一次；关联文章可用标题与摘要卡片展示，详情页保留原始封面。筛选立即更换结果，不给重排添加额外动画。
- 详情页：有真实封面才有大型预览舞台。无真实图片的文章直接进入正文，不凭空复制标题做假封面；发布日期、阅读时间、标签只呈现一组完整信息。
- 导航：桌面固定侧栏、手机底部胶囊导航，手机 logo 是小尺寸字标，不是压过导航的大圆形黑色图标。触摸与键盘均可使用；支持触摸外部关闭弹出菜单。
- 私人应用：卡片是应用工作流的简化界面示意，避免用巨大符号充数；新增应用必须有真实入口、权限校验与数据模型。
- 动效：只保留简短 hover 提示和可用的共享元素转场；取消扫光、卡片缩放和滚动时底栏忽隐忽现。对 \`prefers-reduced-motion\` 禁用动画，任何动画不得影响文本可读性。
- 中文：标题按自然断行而非强迫英文断词，长篇说明用摘要行，细节进入详情。原有产品下载和免责声明保留。

## 自动检查

Pull Request 工作流必须执行 \`npm run check\`、\`npm test\`、\`npm run build\` 与 WebKit 浏览器实测。浏览器用例至少覆盖：
- 1440px 三列和 320px / 390px 单列，无水平溢出；
- 图片比例存在差异，移动端品牌标识单行，手机菜单展开/关闭；
- 列表筛选、卡片点到真实详情、无图文章不生成假的 hero；
- 私人应用中心三个应用入口与真实界面示意；
- 便笺保存、历史、备份导入、跨设备刷新、本地未同步草稿恢复；
- 迭代系统保留真实阶段、圆盘和 Safari 控件。

截图由 \`.github/workflows/verify-iteration-webkit.yml\` 上传。截图可以用于校对视觉质量，但假 API、桌面 WebKit 模拟器都不能代替真实 iPhone 或生产 D1 验证。

## 尚待实机与生产验证

- 在真实 macOS Safari / iPhone Safari / Android Chrome 检查滚动性能、深色模式和系统字体。
- 更精细的 Godly 像素对照、文章侧栏、长篇阅读、评论和后台编辑器的交互审查。
- 正式环境的 Cloudflare D1 migration、登录、版本冲突、恢复、备份和数据权限验证；未通过前不合并到 main。
- 清理旧 \`godly.css\` 与 \`godly-fidelity.css\` 的历史重复选择器，形成单一最终样式层。视觉定稿后再做，避免功能调整期间误删样式。

质量标准不是“页面能打开”或“CI 是绿的”，而是在真实内容、不同大小素材和移动屏幕上都自然、可读、可用。
