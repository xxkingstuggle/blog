# MYZJX Ambient Stage 视觉验收

开发分支：`feat/ambient-stage-editorial-20261114`。本项目只参考公开设计案例的原则，页面只使用仓库中已有的真实图片与真实文案。

## 设计问题与修正

1. **不同心圆角**：原版把卡片 17px、内层 13px、图片 10–14px 独立指定，导致图像与玻璃层形状不齐。新卡片由单一 `--card-radius` 算出中层 `--stage-radius = card-radius - card-inset`，图片 `--image-radius = stage-radius - media-inset`，手机端复用等式。
2. **染色没有越框**：原版在 `overflow:hidden` 的 stage 里面生成色晕，截断了环境光。新版本给 gallery-item 外部创建局部光晕，并在 BaseLayout 添加**唯一的全视口环境层**；图片采样完成后把 RGB 同步到外层，避免通过外部服务取色。桌面 hover/focus 切换，移动端根据视口中心的可见作品选择颜色，双层交叉淡变防止颜色硬切。
3. **所有卡片都像一个模板**：真实图片文章改成图文叠排海报；软件截图使用清晰的产品展示台，且保留下载说明；无图文章使用三种 CSS 构图（排版、纹理、局部图形），不伪造截图。
4. **性能和访问性**：只有一个页面环境层、两片透明渐变，未新增图片/API/外部依赖；低动态偏好不执行淡变，移动端降低染色透明度；取色失败时文本、链接、圆角依然正确。

## 验收标准

- [ ] WebKit/构建/类型检查通过，且没有破坏旧版便笺、过滤和个人迭代系统。
- [ ] 首页和文章列表每个有图卡片的三个圆角满足上述**同心差值方程**，包括 390px 手机。
- [ ] 实际图片颜色通过 `glass-palette` 到达卡片外的背景；切换不同作品，`data-ambient-source` 和显示层发生变化。
- [ ] 局部光晕不被卡片圆角裁剪；大背景采用两层交叉淡变，且不覆盖文字/图像。
- [ ] 至少两种不同文字卡片构图，以及有图海报与软件展示型布局。
- [ ] 320 / 390 / 768 / 1440px 页面无横向溢出；浅色、深色、Safari 支持。
- [ ] 下载最新 Safari 自动截图并人工核查首页、两类卡片、文章与手机截图，发现细节问题优先修复。

## 发布约束

保持独立 PR；图片截图和自动化只用于 WebKit 验证，正式站 `myzjx.com` 不受该分支影响。部署前须完成最新 Vercel 预览检查及真实生产的安全校验。不把“测试已通过”冒称“已完成线上验证”。
