# MYZJX — Kinetic Light v5 / 鼠标与光的连续交互

目标：不改排版、视频、内容、卡片半径和全页背景强度，只改变光对鼠标动作的反馈。

参考交互类型：Aceternity Glowing Effect（临近感应）、Magic UI Magic Card（指针跟随）、Codrops Mouse Flowmap Deformation（速度与方向驱动形变）、Gooey Cursor（迟滞和回弹）。

## 行为验收

1. **临近感应**：鼠标还没进卡片但距离在 136px 内，就有局部光的接近反馈，而不只是 `:hover`。
2. **指针跟随**：一枚核心光跟随鼠标，后面两枚光产生不同时间常数的惯性。反射中心沿卡片坐标平滑移动，不只修改静态投影。
3. **速度与方向**：头部弹簧根据运动速度沿方向拉伸（最大约 1.7 倍），角度平滑转动。慢速时光形收回柔和椭圆。
4. **连续过渡**：鼠标从 A 划向 B，只有一个独立的小型光场，不会在两张卡片间瞬间消失、重新出现。RGB 以 240–280ms 混合过渡，前一张卡片原有的柔光正常淡出。
5. **离开余光**：离开卡片的透明度使用约 225ms 衰减，尾部留光的运动时间常数更长，最后停掉 RAF。
6. **性能限制**：最多三个 200–330px 小合成层，只有一个活跃卡片读取 DOM 尺寸；寻找最近卡片只在 pointermove / scroll 进行，非每帧全页面扫描；没有全屏 canvas/WebGL、视频或外部依赖。
7. **无障碍**：鼠标精确指针且未启用 reduced-motion 的设备才安装此特效；触屏、小内存、省流量、强制颜色和 reduced-motion 自动保留原来的静态光效。

- Safari WebKit 390px / 深色模式：不分配鼠标特效层；老功能、主题弹窗、视频仍可用。
