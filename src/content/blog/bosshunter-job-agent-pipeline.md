今年秋天找工作那阵子，我同时在看两类机会。一类是 AI 产品经理或者产品助理，另一类是偏重动手落地的 AI 应用与 Agent 开发。

真正每天坐在电脑前刷招聘网站的人都知道，找工作最熬人的根本不是跟 HR 聊，而是筛列表。

你把搜索关键词设得稍微宽一点点，刷出来的列表里就混进了一大堆挂羊头卖狗肉的坑。名字叫「产品专员」，点进去一看是打电话卖课的电销；名字叫「AI 工程师」，滑到底下一看是驻场运维外包，或者是要求带过五年以上大团队的资深管理岗。

更别提好不容易碰上一个靠谱的岗位，我还得仔细甄别它到底更看重业务原型还是代码落地，然后再手动去备忘录里复制对应那一版的招呼语和作品集链接。

每天机械地重复这套「点开、扫一眼、关掉、切话术」的动作，不出三天眼睛就看花了。

我就想，既然我整天都在写自动化工具和规则引擎，干嘛不写个脚本帮我自己干这件苦差事？

于是我用 Python、Playwright 加上本地的 SQLite 数据库，写了一套叫 [**BossHunter**](https://github.com/xxkingstuggle/BossHunter) 的求职岗位过滤与记账工具。

很多网上的求职脚本上来就是无脑狂点「立即沟通」，一天海投几百个。说真的，那种做法除了把自己的账号搞进风控黑名单、顺带收获一肚子催收和电销公司的垃圾回复之外，一点用都没有。

我在 `BossHunter` 里把重心全放在了「先打分、再决定开不开腔」上。

我在 `config/jobs.yaml` 配置文件里，把我自己投递的两大方向拆成了两套独立的评分规则。

第一套是 AI 应用与 Agent 开发方向。当脚本读到岗位详情（JD）里出现 `Agent`、`MCP`、`Skill`、`Prompt`、`RAG`、`TypeScript`、`Python`、`Swift` 这些实打实的技术词时，就会往上累加权重分。一旦总分跨过及格线，它匹配出来的招呼语会自动带上我的 GitHub 仓库和 `myzjx.com/software/` 上的开源软件作品页链接。

第二套则是产品经理与产品助理方向。这套规则重点盯 `需求分析`、`原型设计`、`Figma`、`B 端后台`、`教育`、`SaaS`、`跨团队协同` 这些词。匹配通过之后，发出去的招呼语就会自动切换成偏重教育 AI 产品实践和原型落地的那一版介绍。

而在加分项之上，我还设了一道冷酷的「一票否决线」。只要岗位标题或者正文里撞上了 `电销`、`外呼`、`驻场运维`、`催收`，或者工作年限要求远远超出了应届和初级岗位范围，不管它前面加了多少分，脚本直接一票否决当场跳过，绝不浪费一次沟通机会。

跑过几轮之后，我很快发现了第二个问题。

当你换不同的搜索关键词去搜的时候，招聘平台吐出来的岗位列表经常是有大量重合的。如果不记账，脚本在搜完「AI 产品」再搜「Agent 产品」时，就会对着同一家公司的同一个岗位反复点进去看，甚至蠢到给同一个 HR 发两遍招呼。

为了根治重复操作，我在本地塞了一个轻量但极其好使的 SQLite 数据库。

每次脚本在列表里扫到一张新卡片，第一步不是点开，而是先拿平台自带的岗位 ID（万一页面结构拿不到 ID，就自动退化用 `公司名 + 岗位名 + 城市` 拼成唯一键）去 SQLite 表里查一下。只要表里已经有了，直接毫秒级略过。

而每一个真正被脚本审过的岗位，不管最后有没有打招呼，都会在数据库里留下一条清清楚楚的流水账，它得了几分、命中了哪几个加分关键词、是因为撞上哪个否决词被拒掉的、发的是哪一版招呼语模板、发生在哪一秒。

这个账本越积越有用。每天跑完一轮，我直接查一下 SQLite 表，一眼就能看出来今天哪个搜索词捞出来的噪音最多，顺手去 `jobs.yaml` 里微调一下词表权重，越筛越准。

当然，写浏览器自动化脚本最必须敬畏的就是平台的风控边界。

在用 Playwright 驱动本地浏览器的时候，我给自己画了两道死线。第一道是节奏控制，每次翻页、点开详情和发送招呼之间，都会插入贴近真人阅读习惯的随机等待间隔，同时在配置里把单次运行和单日累计的最大沟通次数锁死，绝不搞暴力刷屏。

第二道则是验证码绝对停机边界。招聘网站对异常流量的嗅觉很灵敏，一旦触发了安全验证弹窗、滑块拼图或者异常跳转，脚本最忌讳的就是去硬刚或者尝试破解。我在 `BossHunter` 里写了实时页面状态检查，只要检测到任何验证码或风控弹窗，脚本会立刻把当前进度老老实实写回 SQLite，当场退出自动化循环并弹窗提醒我人工接手。

整套脚本的源码和规则配置模板我都开源在了 [xxkingstuggle/BossHunter](https://github.com/xxkingstuggle/BossHunter) 仓库里。把机械的初筛交给确定性的 YAML 规则和 SQLite 去干，省下来的精力拿去认真改作品、准备每一场真人面试，找工作的节奏一下子就清爽多了。
